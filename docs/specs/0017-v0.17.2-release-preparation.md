# Specification: v0.17.2 Release Preparation

Status: Candidate prepared for review; the `v0.17.2` tag is not pushed.

Target: Workspace package versions, generated changelogs, release banners, and the progress tracker.

## 1. Intent

Prepare a reviewable `0.17.2` patch release candidate that ships the rejected-credentials refusal reason from PR #50.

This is train R2b in `docs/scope/backlog-release-roadmap.md`, specified in `docs/specs/0015-gate-integrity.md` criteria 27 to 31.

## 2. Requirements

1. Set root, runtime, AXI, and site package versions to `0.17.2`.
2. Leave individual skill versions unchanged.
3. Generate release notes from commits after `v0.17.1` using the release tooling.
4. Update the root, runtime, and AXI release banners and the root release badge to describe the rejected-credentials reason and the test guard hint.
5. Record R2b as a prepared candidate in the progress tracker.
6. Run the workspace build, runtime and AXI suites, documentation checks, prose checks, and the release tag check.
7. Do not push a `v0.17.2` tag or publish packages during candidate preparation.

## 3. Acceptance Criteria

1. The root, runtime, AXI, and site manifests all report version `0.17.2`.
2. No per-skill `skill.yaml` version changes are present.
3. Generated changelogs contain the PR #50 commits, and the site changelog is synchronized.
4. Release banners and links reference `v0.17.2` and describe the change accurately.
5. Workspace build, runtime tests, AXI tests, documentation checks, prose checks, and `RELEASE_TAG=v0.17.2 node scripts/verify-release-tag.js` pass.
6. The candidate pull request is merged with passing CI, and no `v0.17.2` tag is pushed.

## 4. Compatibility

Behavior is unchanged: a rejected key still refuses natural-language Jev judgments.
Only the refusal reason changes, so agents and operators can tell a rejected key from an outage.

## 5. Verification Evidence

The candidate was verified on Windows 11 with Node `v24.16.0`.

The workspace build, the runtime suite (383 tests with documentation and prose checks), and the AXI suite (162 tests) passed before the release branch was cut.

PR #50 passed CI on Node 22.x and 24.x.
