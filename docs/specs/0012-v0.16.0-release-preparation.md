# Specification: v0.16.0 Release Preparation

Status: Candidate prepared for review; the `v0.16.0` tag is not pushed.

Target: Workspace packages, source-central-satellite skill distribution, projection output path validation, sync CLI options, release documentation, and generated changelogs.

## 1. Intent

Prepare a reviewable `0.16.0` minor release candidate with central skill distribution and comma-separated sync paths.

Sync reads valid skills from ordered local source directories, stages them in a physical central directory, then links or copies them to selected satellite directories.

The central directory defaults to `~/.agents/skills`, can be configured persistently, and can be overridden for one invocation.

## 2. Requirements

1. Preserve first-source-wins selection while distributing skills through the configured physical central directory.
2. Preserve linked and physical-copy satellite behavior, including migration from a prior central directory recorded in sync state.
3. Accept comma-separated and repeated `--source`, `--target`, and `--physical-target` values, trim surrounding whitespace, and reject empty entries before filesystem writes.
4. Keep `--skill` comma-separated and repeated selection, no-filter all-skills behavior, and positional single-skill compatibility.
5. Resolve projection output paths through existing filesystem ancestors before checking workspace containment.
6. Document sync path selection, central configuration, one-run `--central` overrides, and help examples for customers.
7. Set root, runtime, AXI, and site package versions to `0.16.0`.
8. Leave individual skill versions unchanged.
9. Generate release notes from commits after `v0.15.1` through the release candidate using the release tooling.
10. Update the root, runtime, and AXI release banners to describe the sync distribution changes accurately.
11. Preserve existing runtime package archives and generate a `0.16.0` runtime archive after the final README edits.
12. Run the workspace build, runtime and AXI suites, documentation checks, prose checks, and release checks.
13. Submit the candidate on a release branch with passing required CI checks.
14. Do not push a `v0.16.0` tag or publish packages during candidate preparation.

## 3. Acceptance Criteria

1. The root, runtime, AXI, and site manifests all report version `0.16.0`.
2. No per-skill `skill.yaml` version changes are present.
3. Generated changelogs contain the sync distribution feature commit and the site changelog is synchronized.
4. Release banners and links reference `v0.16.0` and describe source-central-satellite distribution and path options.
5. Existing runtime archive checksums remain unchanged and `reactive-skills-runtime-0.16.0.tgz` exists.
6. Projection output validation accepts in-workspace writes through symlinked workspace paths and still rejects paths that escape the workspace.
7. The CLI help and customer documentation show comma-separated and repeated path options and central directory configuration.
8. Runtime and AXI focused sync suites pass, including path parsing, distribution, help, and compatibility coverage.
9. Workspace build, runtime tests, AXI tests, documentation checks, prose checks, and release checks pass.
10. The release branch contains the implementation commits followed by the candidate preparation commit.
11. The candidate PR is open and required CI checks pass.
12. No `v0.16.0` tag is pushed and no package is published.

## 4. Release Procedure

Commit the feature changes on `release/v0.16.0` before running `pnpm bump:minor` so generated release notes include the feature commit.

Run the minor bump script to update workspace versions, generate release notes, synchronize the site changelog, build the runtime, and create its archive.

Update release banners, repack the runtime archive, run `pnpm build` and `pnpm test:all`, and review the complete candidate diff.

Commit the release preparation changes, push the branch, and open a pull request for CI review.

Keep the release tag unpushed until the pull request is merged and final publication approval is given.
