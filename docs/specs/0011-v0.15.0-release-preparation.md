# Specification: v0.15.0 Release Preparation and Integrity

Status: Release candidate prepared for review; the `v0.15.0` tag is not pushed.

Target: Workspace packages, context-route CLI behavior, release documentation, and generated changelogs.

## 1. Intent

Prepare a reviewable `0.15.0` minor release candidate with optional skill candidates for context routing.

When `--candidates` is omitted, context routing discovers available skill metadata at runtime.

When `--candidates` is supplied, it restricts routing to an explicit array of skill metadata records.

## 2. Requirements

1. Keep context routing candidate-free by default and discover available skill metadata at runtime.
2. Document `--candidates` as skill metadata records with `id`, `skill`, and `summary`, with optional keyword metadata.
3. Preserve an explicit empty candidate array as a request to route without candidates.
4. Keep discovery bounded and ignore directories without supported skill metadata files.
5. Set root, runtime, AXI, and site package versions to `0.15.0`.
6. Leave all individual skill versions unchanged.
7. Generate release notes from commits after `v0.14.0` through the candidate commit using the release tooling.
8. Update the root, runtime, and AXI README release banners to describe automatic skill discovery and explicit skill metadata candidates.
9. Preserve existing runtime package archives and generate a `0.15.0` runtime archive after the final README edits.
10. Run the workspace build and complete runtime and AXI verification suites.
11. Submit the candidate on a review branch with passing required CI checks.
12. Do not push a `v0.15.0` tag or publish packages during candidate preparation.

## 3. Acceptance Criteria

1. The root, runtime, AXI, and site manifests all report version `0.15.0`.
2. No per-skill `skill.yaml` version changes are present.
3. Generated changelogs include the context-route candidate behavior and are synchronized to the site.
4. Release banners and links reference `v0.15.0` and accurately describe context-route candidate selection.
5. Existing runtime archive checksums remain unchanged and `reactive-skills-runtime-0.15.0.tgz` exists.
6. Workspace build, runtime tests, AXI tests, documentation checks, prose checks, and release checks pass.
7. The release branch is available for pull request review and the required CI matrix passes.
8. No `v0.15.0` tag is pushed and no package is published.
